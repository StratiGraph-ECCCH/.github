The StratiGraph-ECCCH GitHub organization collects repositories, software packages and discussions for relevant development work being carried out in
the [StratiGraph](https://stratigraph-eccch.eu) (Knowledge Graphs for Stratigraphy) European project (Horizon Europe Innovation Action).

## Scientific and Technical Committee Board

Registered partners can access the project management board for the Scientific and Technical Committee from the "[Projects](https://github.com/orgs/StratiGraph-ECCCH/projects)" section.
The board includes a [Kanban view](https://github.com/orgs/StratiGraph-ECCCH/projects/4/views/2).
